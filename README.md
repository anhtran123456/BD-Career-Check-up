# BD Career Check-up by Upzi

Trang tĩnh (HTML/CSS/JS thuần, không cần build). Quà tặng của Upzi cho delegates AIESEC NEU – Heading for the Future.

## Cấu trúc
- `index.html` – toàn bộ trang check-up
- `upzi-logo.png`, `upzi-logo-dark.png` – logo Upzi (bản nền sáng / nền tối)
- `gau.png` – mascot Gấu (dùng làm hình trong trang và favicon)
- `.nojekyll` – để GitHub Pages phục vụ file nguyên trạng

## Deploy lên GitHub Pages
1. Tạo repository mới (ví dụ `bd-career-checkup`). GitHub Pages miễn phí yêu cầu repository **Public**.
2. Tải toàn bộ file trong thư mục này lên nhánh `main` (Add file → Upload files).
3. Vào **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
4. Sau 1–2 phút, trang có tại `https://<tên-tài-khoản>.github.io/bd-career-checkup/`.
